# Upstream projects

This repository uses remote references and original configuration glue. It does not vendor complete upstream rule databases.

## OpenClash

- Repository: https://github.com/vernesong/OpenClash
- Purpose: OpenWrt Clash/Mihomo client and configuration manager.

## Mihomo documentation and rules

- Documentation: https://github.com/MetaCubeX/Meta-Docs
- Rule data: https://github.com/MetaCubeX/meta-rules-dat
- Purpose: Mihomo configuration syntax and maintained MRS rule providers.

## Sub-Store

- Repository: https://github.com/sub-store-org/Sub-Store
- Purpose: optional self-hosted subscription conversion, filtering, renaming, deduplication and collection output.

## ACL4SSR

- Repository: https://github.com/ACL4SSR/ACL4SSR
- Purpose: reference for conventional Chinese-user traffic categories and policy-group design.

## Maintenance policy

- Remote rule providers update every 24 hours.
- Review upstream breaking changes before changing provider URLs or formats.
- Preserve upstream attribution and comply with each upstream repository's license if content is copied into this repository.
